# Sales Data Analysis

## Project Overview
This project analyzes sales transaction data using Python, Pandas and Matplotlib.

## Objectives
- Analyze overall sales and profit
- Identify top-performing products
- Compare sales across regions
- Study monthly sales trends
- Practice data cleaning, grouping and visualization

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Dataset
The project uses a sample sales dataset containing order date, region, product, category, quantity, unit price, discount, sales and profit.

## Key Analysis
1. Total sales and total profit
2. Sales by region
3. Sales by product
4. Monthly sales trend

## How to Run
```bash
pip install -r requirements.txt
python sales_analysis.py
```

## Skills Demonstrated
- Data cleaning
- Exploratory Data Analysis (EDA)
- GroupBy and aggregation
- Date/time analysis
- Data visualization
- Business insights
